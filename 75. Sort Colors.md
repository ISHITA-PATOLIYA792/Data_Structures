# 🎨 [75. Sort Colors](https://leetcode.com/problems/sort-colors/)

## 📜 Problem Statement

Given an array `nums` with `n` objects colored **red**, **white**, or **blue**, sort them **in-place** so that objects of the same color are adjacent, with the colors in the order **red**, **white**, and **blue**.

We use the integers `0`, `1`, and `2` to represent the colors:
- `0`: Red
- `1`: White
- `2`: Blue

You **must not use the library's sort function** to solve the problem.

---

### 🔍 Constraints:

- `n == nums.length`
- `1 <= n <= 300`
- `nums[i]` is either `0`, `1`, or `2`.

---

### 🧩 Examples

#### Example 1:
**Input:**  
`nums = [2,0,2,1,1,0]`  
**Output:**  
`[0,0,1,1,2,2]`

#### Example 2:
**Input:**  
`nums = [2,0,1]`  
**Output:**  
`[0,1,2]`

---

## 💡 Approach

### Method: Using a Map to Count Occurrences

1. **Count Occurrences:**  
   Use a `std::map` to count the number of occurrences of `0`, `1`, and `2` in the array.

2. **Rebuild the Array:**  
   Iterate through the map, and for each key-value pair:
   - Write the key into the array `value` number of times.

This approach ensures the array is rebuilt in sorted order.

---

## 👨‍💻 Code Implementation (C++)

```cpp
#include <iostream>
#include <vector>
#include <map>

using namespace std;

void sortColors(vector<int>& nums) {
    // Map to count occurrences of 0, 1, and 2
    map<int, int> countMap;
    for (int num : nums) {
        countMap[num]++;
    }

    // Rebuild the vector in sorted order
    int index = 0;
    for (auto& pair : countMap) {
        int value = pair.first;   // The key (0, 1, or 2)
        int count = pair.second; // The count of that key
        while (count--) {
            nums[index++] = value;
        }
    }
}

int main() {
    // Example 1
    vector<int> nums1 = {2, 0, 2, 1, 1, 0};
    sortColors(nums1);
    cout << "Output: ";
    for (int num : nums1) {
        cout << num << " ";
    }
    cout << endl;

    // Example 2
    vector<int> nums2 = {2, 0, 1};
    sortColors(nums2);
    cout << "Output: ";
    for (int num : nums2) {
        cout << num << " ";
    }
    cout << endl;

    return 0;
}
